# instagram-parser

Навык для Claude Code: рилсы любого открытого аккаунта Instagram превращаются в дословные тексты речи и корпус
(тексты по убыванию просмотров, подписи, комментарии). На этом корпусе Claude собирает цифровой мозг человека:
голос, стиль, подачу, аудиторию. Кыргызский, русский и другие языки.

Работает на Mac, Windows и в облачной сессии Claude Code с iPad или телефона. Нужен только Python, без ffmpeg.
Бесплатно: Apify даёт $5 в месяц (примерно 1500 рилсов), Gemini — бесплатный ключ AI Studio.

## Установка
Скажи своему Claude Code:

> Поставь навык https://github.com/neuroakyl/instagram-parser в .claude/skills/instagram-parser этого репозитория,
> прочитай SKILL.md и подготовь всё по разделу «Подготовка».

Правила, команды и порядок работы — в [SKILL.md](SKILL.md).
