# Парсер Instagram

Скрипт `insta.py` рядом с этим файлом. Только стандартный Python, без ffmpeg: работает на Mac, Windows и в облачной
сессии Claude Code (iPad, телефон). Источник: NeuroAkyl, 27.10.2026.

## Подготовка (один раз)
Человек делает сам, ключи в чат не просить:
1. **Apify** (сбор рилсов): apify.com → регистрация, бесплатно, без карты. Каждый месяц $5 бесплатно, рилс стоит
   ~$0.003, это примерно 1500 рилсов. Дальше один из двух путей:
   - **Коннектор (проще, основной):** claude.ai → Настройки → Коннекторы → Apify → Подключить, войти в Apify.
     В сессии Claude Code включить коннектор в меню сессии. Ключ не нужен, сеть открывать для Apify не нужно.
   - **Ключ:** apify.com → Settings → API & Integrations → Personal API token → `APIFY_TOKEN`.
2. **GEMINI_API_KEY** (расшифровка речи): aistudio.google.com/apikey → Create API key. Бесплатно, квота раз в сутки.

Куда вписать ключи:
- **Облачная сессия (iPad/телефон):** Claude → Code → окружение → Edit → Environment variables: `GEMINI_API_KEY=…`
  (и `APIFY_TOKEN=…`, если без коннектора). Там же **Network access → Full**: звук качается из Instagram, а расшифровка
  идёт в Gemini, на Trusted оба закрыты. Изменения действуют в новой сессии.
- **Свой компьютер:** файл `.env` в папке запуска, те же строки. `.env` не коммитить.

## Порядок
**С коннектором Apify:**
1. Запустить актор `apify/instagram-reel-scraper` с входом `{"username": ["<ник>"], "resultsLimit": 50}`.
   Для обновления добавить `"onlyPostsNewerThan": "2026-09-01"`. Больше 200 рилсов за раз не брать.
2. Забрать результат **только с нужными полями** (иначе в контекст придут комментарии и картинки, это дорого):
   `shortCode, url, timestamp, videoPlayCount, videoViewCount, likesCount, commentsCount, videoDuration, caption, audioUrl, videoUrl`.
   Записать массив в `<папка>/reels.json`.
3. Сразу, пока ссылки не протухли: `python3 insta.py звук <папка>` → `текст <папка>` → `корпус <папка>`.
4. Комментарии для `Аудитория.md` запросить отдельно, полем `latestComments`, по 10–20 лучшим рилсам.

**С ключом (одной командой):**
```
python3 insta.py всё <ник> --limit 50 --out <папка>      # сбор + звук + расшифровка + корпус
python3 insta.py сбор <ник> --newer 2026-09-01 --out <папка>   # только новые рилсы с даты
python3 insta.py текст <папка>                             # дорасшифровать то, что не успели
python3 insta.py корпус <папка>                            # пересобрать корпус.md
```
В скрипт зашиты лимит 200 рилсов за раз и потолок $1 на запуск Apify.

## Куда класть (в цифровом мозге)
- Аккаунт самого человека → `01_Мозг/Материалы/instagram/<ник>/`.
- Чужие аккаунты (конкуренты, образцы) → `Рынок/<ник>/`. Папку создать, когда парсишь первый чужой аккаунт.
- В папке лежат `корпус.md` (читать), `корпус.json` (для скриптов), `reels.json` (всё от Apify, с комментариями) и
  `звук/`. Звук в git не идёт: скрипт сам кладёт `.gitignore`.
- **После каждого шага — commit и push.** В облаке сервер одноразовый.

## Что делать с корпусом (цифровая копия)
Корпус целиком не перечитывать каждый раз: один раз разобрать и записать выводы в мозг.
1. `Голос.md`: как говорит. Любимые слова и обороты (цитатами из корпуса), длина фраз, юмор, обращение к зрителю,
   как начинает (хуки) и как заканчивает (призывы). Язык: на каком говорит, где переходит на другой.
2. Залёты: топ-10 по просмотрам против нижних 10. Чем отличаются тема, хук и структура. Записать в `Соцсети.md`.
3. Факты о человеке из роликов (история, цифры, семья, взгляды) → `Кто я.md` и `Путь.md` с ссылкой на рилс.
   Не додумывать: чего нет в роликах, помечать «уточнить».
4. Комментарии зрителей (`latestComments` в `reels.json`): вопросы, боли, возражения → `Аудитория.md`.
5. Для чужого аккаунта то же самое, но вывод другой: какие структуры и темы можно взять себе.

## Если что-то не так
- «Apify ничего не вернул»: аккаунт закрытый (попросить открыть на время) или ник с ошибкой.
- «Звук не скачался»: ссылки Instagram живут несколько часов. Запустить `сбор` ещё раз, готовое не перекачивается.
- «Квота Gemini кончилась»: продолжить завтра командой `текст`, готовое не пропадёт.
- Текст подозрительно короткий: скрипт сам переспрашивает Gemini, если слов меньше 1.5 в секунду.
  Если всё равно мало, `--model gemini-3.8-flash`.
